Cosine Similarity Definition
\(\cos(\theta) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2} = \frac{\sum_{i=1}^D u_i v_i}{\sqrt{\sum_{i=1}^D u_i^2} \sqrt{\sum_{i=1}^D v_i^2}}\)
Ranges from -1.0 (exact opposite meaning) to +1.0 (identical semantic direction). Completely invariant to vector length!
Why Not One-Hot Vectors? In a one-hot representation, every word vector is orthogonal (\(\mathbf{u} \cdot \mathbf{v} = 0\)). The distance between "hotel" and "motel" is identical to the distance between "hotel" and "banana". Dense embeddings solve this by encoding continuous semantic relations!
Module 04 • Self-Supervised Learning

🎯 Word2Vec Architecture: CBOW vs Skip-Gram

How do we train millions of word vectors without hand-labeled data? Word2Vec invented self-supervised training using sliding context windows: CBOW predicts a center target word from its surrounding context, while Skip-Gram predicts surrounding context words given a center target word.

🔄 Interactive Sliding Context Window & Architecture Toggle
Click any word to place the Center Target (Window Size = 2):
Context Window (C): ±2 words
Negative Sampling vs Full Softmax O(K) VS O(V)
In a vocabulary of \(V = 100,000\) words, calculating the softmax denominator \(\sum_{w=1}^V e^{\mathbf{v}'_w \mathbf{v}_c}\) requires 100,000 exponentiations for every single training step!
Negative Sampling Objective
\(\mathcal{L} = -\log \sigma(\mathbf{v}'_{w_O} \cdot \mathbf{v}_{w_I}) - \sum_{i=1}^k \mathbb{E}_{w_i \sim P_n(w)} [\log \sigma(-\mathbf{v}'_{w_i} \cdot \mathbf{v}_{w_I})]\)
Instead of classifying across all 100,000 classes, the model solves 1 true positive binary classification and updates just \(k=5\) randomly sampled negative noise words. Efficiency increases by over 20,000×!
When to Choose CBOW vs Skip-Gram? ENGINEERING RULES
  • CBOW (Continuous Bag of Words): Trains multiple times faster. Excellent for large datasets with frequent, common words. Smooths over rare words by averaging context.
  • Skip-Gram: Slower to train, but far superior for rare words and smaller corpora, because each context pair receives its own individual gradient update.

Why 'pre' Padding is Crucial for Basic RNNs VANISHING SIGNAL
If you use padding='post' with an unmasked Vanilla RNN, the final timestep \(t_T\) receives a stream of multiple useless zeros: \[h_T = \tanh(W_h h_{T-1} + W_x \cdot \mathbf{0} + b)\] The zero inputs dilute the hidden state, effectively washing away the real sentiment accumulated earlier! 'pre' padding places all zeros at the start so the model reads the real words last.

The 6 Canonical LSTM Equations
\(f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)\)     (Forget Gate)
\(i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)\)     (Input Gate)
\(\tilde{C}_t = \tanh(W_c \cdot [h_{t-1}, x_t] + b_c)\)     (Candidate State)
\(C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t\)     (Cell State Conveyor Belt!)
\(o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)\)     (Output Gate)
\(h_t = o_t \odot \tanh(C_t)\)     (Hidden State Output)
The Secret to Vanishing Gradient Immunity: Notice the cell state update: \(C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t\). It is an additive linear conveyor belt! When \(f_t = 1\), the gradient \(\frac{\partial C_t}{\partial C_{t-1}} = 1.0\). Gradients flow back through 100 timesteps completely unattenuated!
Module 09 • Streamlined Recurrence

⚡ Gated Recurrent Unit (GRU): Streamlined & Fast

Can we retain the memory advantages of an LSTM while slashing compute time and parameter count? Introduced by Cho et al. in 2014, the GRU merges the cell state and hidden state into a single vector and coordinates memory with just two gates: Reset and Update.

🔀 Inside the GRU Cell Structure
2 GATES ONLY
Update Gate (\(z_t\)): 0.60
Reset Gate (\(r_t\)): 0.75
⚖️ Architectural Face-Off: LSTM vs GRU
COMPUTE BENCHMARK
Dimension LSTM GRU
Gates Count 3 (Forget, Input, Output) 2 (Reset, Update)
Hidden/Cell States 2 separate vectors (\(C_t\) and \(h_t\)) 1 unified vector (\(h_t\))
Parameters Formula \(4 \times (d_h(d_h + d_x) + d_h)\) \(3 \times (d_h(d_h + d_x) + d_h)\)
Training Speed Baseline (100% time) ~25% - 30% Faster
Best Used For Long narratives, code, books Short reviews, tweets, mobile/edge
GRU Mathematical Gates
\(z_t = \sigma(W_z \cdot [h_{t-1}, x_t])\)     (Update Gate)
\(r_t = \sigma(W_r \cdot [h_{t-1}, x_t])\)     (Reset Gate)
\(\tilde{h}_t = \tanh(W \cdot [r_t \odot h_{t-1}, x_t])\)     (Candidate State)
\(h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t\)     (Linear Interpolation!)

Why read language only from left to right when human readers comprehend both past and upcoming context? A Bidirectional LSTM runs two independent recurrent layers simultaneously—one forward, one backward—concatenating their hidden vectors at every single token.

Why Unidirectional Models Fail on Negation THE NEGATION TRAP

Module 11 • Sequence Regularization

🛡️ Sequence Regularization: SpatialDropout1D & Recurrent Dropout

Why does standard dropout fail on sequences? Dropping random scalar values across words corrupts word representations without preventing co-adaptation. Discover how SpatialDropout1D drops entire feature channels and how Recurrent Dropout stabilizes memory gates across time.

🎲 Interactive Tensor Dropout Pattern Visualizer (Shape: Batch × Time × Dim)
Dropout Rate: 0.25
Active Pattern: Drops entire feature columns across all timesteps
SpatialDropout1D Mechanics NLP BEST PRACTICE
If an embedding vector has 128 dimensions, dimension #42 might encode "formality" or "past tense". If standard dropout zeros dimension #42 for word 1 but keeps it for word 2, the model relies on noisy inconsistencies. SpatialDropout1D drops dimension #42 across every single word in the sentence, forcing the model to learn distributed, redundant feature representations!
Recurrent Dropout (Gal & Ghahramani, 2016) BAYESIAN DROPOUT
Standard dropout between recurrent states \(h_{t-1} \to h_t\) creates exponential variance decay as the sequence grows: \[h_t = \text{dropout}(W_h h_{t-1}) \implies \text{signal vanishes over } t=100\] Recurrent Dropout samples one single binary mask at timestep 0 and keeps that exact same mask across all timesteps \(1 \dots T\), maintaining memory stability!
Module 12 • Architectural Limits

⏳ The RNN Bottleneck & Why Hardware Demanded Transformers

Why did deep learning abandon RNNs despite decades of success? Explore the dual crises that doomed recurrence: the Information Compression Bottleneck and the Sequential Processing Barrier that left modern GPU hardware starved of parallel matrix operations.

🖥️ GPU Parallelism Benchmark: Sequential Recurrence vs Transformer Matrix Multiply
O(T) VS O(1) TIMELINE
GPU Tensor Core Utilization: RNN = 12% | Transformer = 96%
Bottleneck 1: The Fixed Context Vector Trap INFORMATION THEORY
In an RNN or Seq2Seq encoder, a 100-word paragraph must be squashed into a single fixed-length vector \(h_{100} \in \mathbb{R}^{512}\). Try cramming a 500-page book into a single 512-number tweet—details at the beginning are irrevocably blurred or overwritten. Attention solves this by giving the model a direct, unconstrained highway to peek back at any word anytime!
Bottleneck 2: The Non-Parallelizable Loop COMPUTE BOTTLENECK
A modern NVIDIA H100 GPU boasts over 16,000 CUDA cores and 500 Tensor cores designed to multiply massive matrices simultaneously. In an RNN, token \(t_{50}\) mathematically cannot start until token \(t_{49}\) has completed its forward pass! Thousands of GPU cores sit completely idle waiting for the next sequential timestep.

Scaled Dot-Product Attention Equation
\(\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q} \mathbf{K}^T}{\sqrt{d_k}}\right) \mathbf{V}\)
• \(\mathbf{Q} \mathbf{K}^T\): Computes similarity between every query and all keys simultaneously.
• \(\frac{1}{\sqrt{d_k}}\): Prevents dot products from exploding in high dimensions (which would push softmax into near-zero gradient regions).
• \(\text{softmax}(\dots)\): Normalizes rows into true probability distributions summing to 1.0.

    num_heads=4, 
    key_dim=32
)
# Self-attention: Query = Key = Value = x
