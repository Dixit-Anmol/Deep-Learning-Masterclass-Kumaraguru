## 📖 Executive Overview

This repository houses the official curriculum, executable GPU-ready laboratories, interactive web visualizers, assessment quizzes, presentation slide decks, and instructor delivery guides for the **5-Day Deep Learning Masterclass** delivered at **Kumaraguru Institutions** from **November 16 to 20, 2026**.

The curriculum is structured to take engineers, researchers, and students from foundational convolutional mathematics to bleeding-edge production architectures:
* **Day 1 (Nov 16):** Convolutional Neural Networks (CNNs), Computer Vision & CIFAR-10 Optimization
* **Day 2 (Nov 17):** Sequence Models, Word Embeddings (Word2Vec/GloVe), LSTMs, GRUs & Attention Foundations
* **Day 3 (Nov 18):** Generative Adversarial Networks (GANs, DCGAN, cGAN, Pix2Pix, CycleGAN, StarGAN)
* **Day 4 (Nov 19):** Modern Foundation Models (Transformers, BERT, GPT, Scaling Laws & LoRA PEFT)
* **Day 5 (Nov 20):** Competitive Deep Learning, Validation Strategy, Stacking, Test-Time Augmentation & Kaggle Playbook

## 🧩 Pedagogical Highlights: Interactive Visualizers & Step-by-Step Math

Each interactive visualizer provides a dedicated **Step-by-Step Mathematical Walkthrough** that demystifies abstract equations with intuitive analogies and concrete numerical toy examples:

### 📐 Example: Scaled Dot-Product Attention
$$	ext{Attention}(Q, K, V) = 	ext{softmax}\left( rac{Q K^T}{\sqrt{d_k}} ight) V$$

1. **Where Did Everything Come From?**
   * **$Q$ (Query = "What I want"):** Generated by $W_Q$. A word seeking context (*"Who has attributes relevant to me?"*).
   * **$K$ (Key = "What I have"):** Generated by $W_K$. A word advertising its attributes (*"I am a warm temperature descriptor"*).
   * **$K^T$ (Key Transposed):** Flips the matrix to compute pairwise match dot products in a single matrix multiplication.
   * **$\sqrt{d_k}$ (The Variance Stabilizer):** Scales scores down to prevent softmax gradient saturation.
   * **$	ext{softmax}(\cdot)$ (The Probability Normalizer):** Converts raw scores into percentage weights summing to 1.0 (100%).
   * **$V$ (Value = "The Information Content"):** Generated by $W_V$. The actual semantic meaning that gets blended forward.

2. **Concrete Numerical Walkthrough ("Hot sun", $d_k=4 \implies \sqrt{d_k}=2$):**
   * $Q_{	ext{sun}} = [2, 1, 0, 0]$, $K_{	ext{Hot}} = [2, 2, 0, 0]$, $K_{	ext{sun}} = [0, 2, 0, 0]$
   * $V_{	ext{Hot}} = [10, 0]$ (*"Heat"*), $V_{	ext{sun}} = [0, 10]$ (*"Bright star"*)
   * **Step 1 (Raw Dot Products $Q K^T$):** Match with "Hot" $= (2	imes 2) + (1	imes 2) = 6$; Match with "sun" $= 2$. Scores $= [6, 2]$.
   * **Step 2 (Scaling $\div \sqrt{d_k}$):** $6 \div 2 = 3$; $2 \div 2 = 1$. Scaled scores $= [3, 1]$.
   * **Step 3 (Softmax):** $e^3 pprox 20.085$, $e^1 pprox 2.718 \implies$ "Hot" weight $= 88\%$ ($0.88$); "sun" weight $= 12\%$ ($0.12$).
   * **Step 4 (Weighted Blend $	imes V$):** $0.88 	imes [10, 0] + 0.12 	imes [0, 10] = [8.8, 1.2]$.
   * **Takeaway:** "sun" is enriched with 88% thermal context from "Hot" to become $[8.8, 1.2]$ — a *"hot, bright sun"*.

## 🛠️ Local Environment Installation

While all notebooks run seamlessly on Google Colab, you can replicate the environment locally:

```bash
# 1. Clone repository
git clone https://github.com/Dixit-Anmol/Deep-Learning-Masterclass-Kumaraguru.git
cd Deep-Learning-Masterclass-Kumaraguru

# 2. Create virtual environment
python -m venv dl_env
source dl_env/bin/activate  # On Windows: dl_env\Scripts\activate

# 3. Install core PyTorch & Deep Learning stack
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
pip install transformers datasets accelerate peft evaluate
pip install opencv-python albumentations scikit-learn matplotlib seaborn jupyter
```
